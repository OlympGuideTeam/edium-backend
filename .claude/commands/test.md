Напиши тесты для указанного файла/функции/сервиса.

Для **Go-кода**:
- Используй стандартный `testing` пакет + `testify` если уже используется в проекте
- Unit-тесты для сервисов: мокай repository через интерфейсы
- Integration-тесты для repository: используй реальную БД (testcontainers или docker)
- Называй тесты: `Test{ИмяФункции}_{сценарий}`, например `TestSendOTP_Success`
- Покрой: happy path, граничные случаи, ошибочные сценарии
- Комментарии и названия тестов — на русском

Для **Python ML-кода**:
- Используй `pytest`
- Мокай вызовы OpenAI API через `unittest.mock.patch`
- Тестируй парсинг chapters-файлов, OCR-fallback логику, генерацию датасета
- Фикстуры в `conftest.py`

Запусти тесты после написания:
- Go: `go test ./...` в директории сервиса
- Python: `cd ml && pytest -v`
