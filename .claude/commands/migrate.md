Помоги создать новую SQL-миграцию для указанной задачи.

**Правила Flyway-миграций в этом проекте:**
- Формат имени: `V{следующий_номер}__{краткое_описание}.sql`
- Например: `V003__add_quiz_table.sql`
- Расположение: `<service>/migrations/`
- Миграции **append-only** — никогда не изменяй существующие файлы
- Всегда добавляй `NOT NULL` + дефолт или nullable явно
- Индексы для всех FK и часто используемых фильтров
- Используй `created_at TIMESTAMPTZ DEFAULT NOW()` для временных меток

**Посмотри существующие миграции** в `migrations/` чтобы:
1. Определить следующий номер версии
2. Сохранить единый стиль

**После создания:**
- Проверь SQL синтаксис
- Убедись, что DOWN-миграция возможна (если нужна)
- Добавь комментарий в файл зачем нужна эта миграция
